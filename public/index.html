Generador

Seis recuadros, uno por tipo. Cada identificador aparece descompuesto en prefijo, cuerpo y control, con el cálculo que produce ese control debajo. El CIF lleva selector con los 17 tipos de entidad. Se pulsa el valor y se copia.

API

Los mismos generadores servidos en JSON, para consumirlos desde código. Cada petición requiere un token de acceso; solicítalo al administrador y envíalo en la cabecera Authorization. 

Authorization: Bearer <token>

GET /documentos/nif             un valor
GET /documentos/nif/25          25 valores
GET /documentos/cif/10?tipo=B   por tipo de entidad
GET /documentos/nif?detalle=1   con el cálculo

documentos: nif · nie · cif · nss — financiero: iban · tarjeta
vehiculos: matricula — miscelanea: cups · imei
Máximo 1000 por petición. Sin token válido, todas las rutas devuelven 401.

Ninguno de estos valores corresponde a una persona, entidad o cuenta real. Son combinaciones que cumplen el algoritmo de control, pensadas para poblar formularios y probar validadores. No sirven para ningún trámite.
